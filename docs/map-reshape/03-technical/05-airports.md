# 03.05 — Layer 4: airports

## Inputs
Layer 2 (`H0`, to level the site); layer 3 (rivers/lake: no runway across water); layer 1 (cover cleared to `grass/apron`);
spec `airports:`; anchors. Position is free within the dependencies: Tocumen on the airport shore (existing), optional Albrook-style
airfield.

## Algorithm
1. Site: runway centrelines (authored). Flatten rect = hull of runways + apron + `blend` (existing `flatten` mechanism,
   `tocumen-airport` rect [[5000,300],[6000,2100]], blend 200, level auto).
2. Runway: length, width, bearing from the authored line; `flat_tolerance` 0.05 m along the centreline (existing target).
3. Apron/terminal: rectangle near the terminal landmark; taxiway = polyline joining runway ends to apron (generated by the
   route kind `taxiway`, width 23 m default).
4. Connection: a service road node at the terminal for layer 5 (main roads read it as a destination).
5. Obstacle rule: no buildings (layer 9) within `approach` of the runway axis higher than the airport cap (greybox rule only).

## Pure test
Runway centreline height spread <= 0.05 m after all deltas; runway inside land and outside water bodies; runway length and spacing
equal the spec; terminal reachable (road node exists); non-crossing of rivers. Mutation: perturb the flatten level by 0.3 m,
flatness test red.
